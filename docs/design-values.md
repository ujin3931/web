# 디자인 값 목록 (정리 전 원본)

- 출처: 첨부 스크린샷 4장 (① 홈 상단, ② 신상품 목록, ③ 로그인 모달, ④ 한가위 세일 목록). 모두 2000×1093px.
- Figma 파일은 이 환경에 Figma 커넥터가 연결되어 있지 않아 직접 읽지 못했습니다. 아래 값은 모두 스크린샷을 픽셀 단위로 측정한 값입니다.
- 단위는 스크린샷 px입니다. 실제 CSS px과의 배율(1x/2x)은 확인하지 못했습니다.
- 색은 WebP 압축과 글자 안티에일리어싱 때문에 ±몇 단계 오차가 있을 수 있습니다.
- 제외한 것: 상품 썸네일, 이미지 안의 그래픽·문구(예: "최저가 도전", "500개만 이가격!"), 상단 우측 프로모션 이미지 배너, 카카오·Google·Facebook·Apple 로고, 입력창 커서.
- "비슷한 값" 열은 묶을 후보만 표시한 것입니다. 합치거나 이름을 붙이지 않았습니다.
